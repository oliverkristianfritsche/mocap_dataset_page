# ULTRA-MoCap dataset page

Kinematics Analysis** (*Scientific Data* 13, 622, 2026).

- Live page: https://oliverkristianfritsche.github.io/mocap_dataset_page/
- Paper: https://doi.org/10.1038/s41597-026-06687-5
- Dataset (figshare, CC BY-NC-ND 4.0): https://doi.org/10.6084/m9.figshare.28751156.v1
- Benchmark code: https://github.com/oliverkristianfritsche/UpperBody_Kinematics_Prediction
- Processing scripts: https://github.com/oliverkristianfritsche/MocapDatasetScripting_REALLAB
